# Desktop artwork

`ipatool.svg` is the original vector source for the desktop application icon,
under the repository's MIT license. `ipatool.icns` contains PNG representations
at standard and Retina sizes. Both files are local build resources, not Apple
framework images or account material.

The current ICNS was generated by rendering the SVG to a 1024-pixel PNG with
resvg, scaling PNG representations with macOS `sips`, and packaging the standard
`icp4`, `ic11`, `icp5`, `ic12`, `ic07`, `ic13`, `ic08`, `ic14`, `ic09`, and `ic10`
PNG chunks. Native `iconutil --convert iconset` successfully decoded the result;
all decoded representation dimensions matched their intended sizes.

The application-bundle build copies the checked-in ICNS. It does not need a
Python, Swift, image-conversion, or external helper executable at runtime.
