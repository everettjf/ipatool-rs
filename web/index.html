03 / STATUS

Working, with clear limits.

Live macOS checks covered account login, free purchases, purchase history, MCP listing and an already owned purchase, native Mac PKG downloads, and a compatible iPhone app's Mac IPA with SINF. Real 2FA, successful token recovery, and private FairPlay decryption still need live validation.
