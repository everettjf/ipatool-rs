02 / GET STARTED

Build. Run. Explore.

Current release target: macOS on Apple Silicon. You need a Rust toolchain and macOS signing tools.

QUICK START macOS arm64
git clone https://github.com/everettjf/ipatool-rs.git
cd ipatool-rs
scripts/build-macos.sh --arm64
./target/release/ipatool-macos-arm64 search ScriptWidget --platform macos

03 / STATUS

Working, with clear limits.

Live macOS checks covered account login, a free purchase, purchase history, MCP listing, and native Mac PKG downloads. Real 2FA, an IPA/SINF offer, and private FairPlay decryption still need end-to-end validation.
